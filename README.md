# Python Trivia Quiz

An interactive 5-question command-line trivia game built in Python.

## Features
- **Colored Terminal Feedback:** Displays green and red text for right and wrong answers.
- **Timed Pauses:** Uses Python's `time` module for a smooth, interactive pace.
- **Smart Input Handling:** Ignores uppercase/lowercase differences and extra spaces.
- **Score Tracking:** Calculates your final score out of 5 with custom feedback at the end.

## How to Run
Make sure Python 3 is installed on your computer, then run:
```bash
python quiz_game.py
```
